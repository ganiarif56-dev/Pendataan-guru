Panduan Penggunaan

Versi awal frontend ini dibuat sederhana agar guru dapat langsung memahami alurnya.

👩‍🏫 Untuk Guru

Buka link → pilih Isi Data Saya → isi data → simpan. Pada tahap backend, data akan otomatis dikirim ke Google Spreadsheet.

🧑‍💼 Untuk Admin

Admin dapat melihat data, mencari guru, memeriksa kelengkapan, dan nantinya melakukan verifikasi.

☁️ Penyimpanan

Frontend ini belum terhubung ke Google Spreadsheet. Integrasi akan dibuat pada tahap backend menggunakan Google Apps Script/API.
